# Foodify
[Watch the project demo!](https://www.loom.com/share/602dcdf17a6e42ae9c8c208e99eae0f5)

Foodify is a web application designed to help users discover and manage recipes. The application allows users to search for recipes, view detailed recipe information.

## Project Overview

This project includes the following functionalities:
- **Search for Recipes**: Users can search for recipes using a search bar.
- **View Detailed Recipe Information**: Displays recipe details such as ingredients, preparation steps, and cooking time.
- **Sign Up, Login, and Logout**: Users can create accounts, log in, and log out.

## Project Structure

### `index.html`

This is the main HTML file for the application. It includes:
- **Header**: Contains a back button, the title "Foodify", and a search bar.
- **Content**: Displays the homepage message and meal containers.
- **Footer**: Provides copyright and contact information.

### `script.js`

This JavaScript file handles the application logic:
- **Search Functionality**: Retrieves recipes from an API based on user input and displays them.
- **Back Button Functionality**: Allows users to return to the homepage.
- **Meal Display**: Formats and displays recipe details, including instructions.

### API Integration

The application uses the Tasty API to fetch recipe data.
